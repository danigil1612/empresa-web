# MVP

## Objectiu del MVP

Crear una primera versió funcional i professional de la web corporativa amb accés privat a un dashboard per empreses clientes.

## Funcionalitats MVP

### Web pública

- Home.
- Pàgina de producte.
- Pàgina “Com funciona”.
- Formulari de contacte.
- Accés a login.

### Dashboard client

- Login segur.
- Pàgina principal de resum.
- Dades bàsiques de l’empresa.
- Apartat d’usuaris.
- Apartat d’informes o mètriques bàsiques.
- Configuració bàsica.

### Admin intern

- Crear empreses clientes.
- Crear usuaris.
- Assignar rols.
- Veure formularis de contacte.
- Activar o desactivar comptes.

## Criteri d’èxit

El MVP es considera correcte si:

- La web pública es veu professional.
- El formulari de contacte funciona.
- Els clients poden iniciar sessió.
- Cada empresa veu només les seves dades.
- L’admin pot gestionar empreses i usuaris.
- El projecte està documentat.
- El projecte està pujat a GitHub.
