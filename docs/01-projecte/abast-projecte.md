# Abast del projecte

## Inclòs en el MVP

- Home corporativa.
- Pàgina de producte o servei.
- Pàgina “Com funciona”.
- Pàgina de contacte.
- Formulari de contacte.
- Login.
- Dashboard bàsic per empreses clientes.
- Panell admin bàsic.
- Base de dades PostgreSQL.
- API backend amb Node.js/NestJS.
- Frontend amb Nuxt/Vue i TypeScript.
- Disseny responsive.
- Desplegament inicial.

## No inclòs inicialment

- Pagaments online.
- Facturació avançada.
- App mòbil.
- Notificacions push.
- Exportacions avançades PDF/Excel.
- Integracions externes complexes.
- Estadístiques avançades.

## Possible fase 2

- Multiidioma complet.
- Sistema de notificacions.
- Exportació d’informes.
- Factures.
- Pagaments.
- Estadístiques avançades.
