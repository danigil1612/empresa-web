# Empresa Web

Projecte professional per desenvolupar una web corporativa amb accés privat a dashboard per a empreses clients.

## Stack previst

- Nuxt / Vue
- TypeScript
- Node.js / NestJS
- PostgreSQL
- Prisma
- Tailwind CSS
- Docker

## Estructura principal

- `apps/web`: frontend públic i dashboard.
- `apps/api`: backend API.
- `database`: Prisma, migracions i seeds.
- `docs`: documentació professional del projecte.
- `docker`: configuració Docker.
