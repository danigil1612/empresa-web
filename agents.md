
# Pulse Web Project


## Context

This project is the corporate website for Pulse.

Pulse is a B2B platform for companies, HR teams and leadership teams. It helps detect emotional wear, disengagement and team wellbeing signals before they affect performance.

## Important scope

The customer dashboard already exists.

This project must NOT include:

- Custom backend
- Database
- PostgreSQL
- Docker
- Custom login
- Authentication
- Dashboard development
- API development
- Admin panel

The website only needs a button/link to the existing external dashboard.

The dashboard URL must be configured using:

NUXT_PUBLIC_DASHBOARD_URL

## Tech stack

Use:

- Nuxt 3
- Vue 3
- TypeScript
- CSS
- Responsive design

The frontend is located in:

apps/web

## MVP pages

Create or improve these pages:

- Detecta el desgaste de tu equipo antes de que afecte al rendimiento.
